# 命令与征服 3 修改器

适用于《命令与征服 3：泰伯利亚战争》和《凯恩之怒》的单人修改器。界面和安全策略参考 [RedAlert2Trainer](https://github.com/zhaoshuoxp/RedAlert2Trainer)：连接前校验游戏文件指纹和唯一特征签名，正常退出时恢复程序安装的全部内存补丁，不修改游戏文件。

## 已验证版本

- 泰伯利亚战争 1.09、EA 2025 更新版 1.10
- 凯恩之怒 1.02、EA 2025 更新版 1.03

## 功能

- 设置资金、增加 10 万、保持最低金额
- 无限电力
- 我方单位和建筑无敌，可选保护剧情初始单位
- 护盾不减
- 快速生产
- 凯恩之怒全球征服资金

## 使用

1. 进入单人战役或遭遇战地图。
2. 运行 [`dist/CNC3Trainer-Portable.exe`](dist/CNC3Trainer-Portable.exe)，接受管理员权限提示。
3. 点击“连接游戏”。游戏暂停或在后台时，恢复一帧后才能读取玩家数据。
4. 正常关闭修改器会恢复它安装的全部指令。

热键仅在游戏位于前台时响应。小键盘 `*` 连接/断开，小键盘 `1`～`7` 对应界面中的功能。

| 小键盘 | 功能 |
|---|---|
| `*` | 连接游戏／断开并恢复 |
| `1` | 开关保持最低金额 |
| `2` | 开关无限电力 |
| `3` | 开关我方无敌 |
| `4` | 开关剧情初始单位保护 |
| `5` | 开关护盾不减 |
| `6` | 开关快速生产 |
| `7` | 开关《凯恩之怒》全球征服资金 |

> 仅限单人模式。不要在多人或在线对局中使用。

## 构建

在 Windows PowerShell 中运行 `./build.ps1`。项目使用系统自带的 .NET Framework C# 编译器，不需要额外安装开发工具。
