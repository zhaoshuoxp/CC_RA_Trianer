# Third-party components

The executable bundles Python 3.12 (PSF license), the PyInstaller bootloader (GPL with its distribution exception), and Keystone Engine 0.9.2 (core: GPLv2; Python binding: BSD license). The user interface uses native Windows controls.

Upstream source and license information:
- https://github.com/python/cpython/tree/3.12
- https://github.com/pyinstaller/pyinstaller
- https://github.com/keystone-engine/keystone/tree/0.9.2

Keystone binding license is included in KEYSTONE_BINDING_LICENSE.txt. Engine address research references are listed in README.md. No third-party game binaries are included.
